# duna-audio

Audio de las sesiones de Duna que no van dentro de la app (los programas).
Se sirve con GitHub Pages: `https://93dafer.github.io/duna-audio/<programa>/<programa>-<paso>.m4a`.
AAC mono, 80 kbps.

Las sesiones sueltas de las colecciones de Explorar van en `explorar/<id>.m4a`
(AAC mono, 64 kbps).
